# RT Fogões - Landing Page Moderna (GitHub Pages)

Esta landing page foi desenvolvida em **HTML5, CSS3 e JavaScript puros** para você hospedar diretamente no **GitHub Pages** e utilizar em seu portfólio.

## 📁 Estrutura de Arquivos
- `index.html`: Código semântico com todas as seções (Hero, Sobre, Serviços, Simulador, Avaliações, Contato e Rodapé).
- `style.css`: Estilização moderna, responsiva para celulares e computadores, com paleta elegante e tipografia editorial.
- `script.js`: Gerador automático de link do WhatsApp com os dados do orçamento.
- `images/`: Fotos em alta resolução dos serviços (Limpeza de bicos, Troca de lã de vidro, Instalação, Kit gás, Queimadores e Cooktop).

## 🚀 Como colocar no GitHub Pages
1. Crie um novo repositório no seu GitHub (exemplo: `rt-fogoes`).
2. Faça upload dos arquivos desta pasta (`index.html`, `style.css`, `script.js` e a pasta `images/`).
3. No seu repositório no GitHub, clique em **Settings** > **Pages**.
4. Em **Build and deployment** > **Branch**, escolha `main` (ou `master`) e `/ (root)`.
5. Clique em **Save**. Em instantes seu site estará online gratuitamente em:
   `https://seu-usuario.github.io/rt-fogoes/`

## ✨ Destaques para seu Portfólio
- Totalmente responsivo (Mobile-first).
- Integração direta com WhatsApp pré-formatando o orçamento com tipo de fogão, marca e bairro.
- Imagens dos serviços reais (Porto Alegre).
- Avaliações 5 estrelas reais do Google.
